# لوڈو — Progressive Web App

خالص HTML / CSS / JavaScript (ES modules)، کوئی بلڈ ٹول یا لائبریری نہیں۔

## فولڈر ڈھانچہ

```
ludo/
├─ index.html              صفحہ (مینو + بورڈ + اوورلے)
├─ manifest.webmanifest    PWA کی معلومات (نام، آئیکن، رنگ)
├─ sw.js                   سروس ورکر — آف لائن کے لیے سب کچھ کیش کرتا ہے
├─ package.json            npm test / npm start
├─ css/style.css
├─ js/
│  ├─ config.js            بورڈ کی جیومیٹری: 52 گھروں کا ٹریک، سیف گھر، اڈے/ہوم کی جگہیں
│  ├─ engine.js            خالص رولز: پانسہ، چال، کٹائی، ہوم کالم، جیت (DOM کے بغیر)
│  ├─ ai.js                کمپیوٹر کھلاڑی
│  ├─ game.js              کنٹرولر: باری کا لوپ، وقفہ، محفوظ کھیل (localStorage)
│  ├─ ui.js                گوٹیوں کی حرکت، پانسہ، چپس، اوورلے
│  ├─ audio.js             Web Audio کے ذریعے آوازیں
│  ├─ strings.js           تمام اردو متن
│  └─ main.js              مینو، انسٹال بٹن، سروس ورکر رجسٹریشن
├─ assets/
│  ├─ board/LUDO_BOARD.svg   اصل ڈیزائن (ایڈٹ کے لیے)؛ board.webp اس کی تیار کردہ تصویر ہے جو گیم دکھاتا ہے (تیز چلتی ہے)
│  ├─ backgrounds/         bg-blue.webp (استعمال میں)، bg-deco.webp (متبادل: css/style.css میں --bg-img بدل دیں)
│  ├─ pieces/*.png         192px (اصل 4096px سے چھوٹی کی گئیں)
│  ├─ sounds/*.mp3         dice, move, kill, win, game-over
│  └─ icons/               PWA آئیکن
└─ tests/simulate.js       2000 بے ترتیب کھیلوں سے رولز کی جانچ
```

## چلانا

PWA کے لیے `http://localhost` یا HTTPS ضروری ہے (فائل پر ڈبل کلک سے سروس ورکر نہیں چلتا):

```
cd ludo
npx serve .          # یا: python3 -m http.server 8000
```

ٹیسٹ: `npm test`

## آن لائن شائع کرنا

فولڈر جوں کا توں GitHub Pages، Netlify یا Cloudflare Pages پر ڈال دیں (سب راستے relative ہیں، سب ڈائرکٹری میں بھی چلے گا)۔
Android Chrome میں مینو کے اندر "ایپ انسٹال کریں" بٹن آئے گا؛ iPhone پر Safari → Share → Add to Home Screen۔

## کوئی فائل بدلیں تو

`sw.js` میں `VERSION` (مثلاً `ludo-v3`) بڑھا دیں تاکہ پرانا کیش بدل جائے۔

## بورڈ کا نقشہ (SVG سے نکالا گیا)

- 15×15 گرڈ، ہر گھر 50px۔ ٹریک گھڑی کی سمت: سبز ← سرخ ← نیلا ← پیلا۔
- سٹارٹ گھر (ٹریک انڈیکس): سبز 1، سرخ 14، نیلا 27، پیلا 40۔ ستارے ان سے 8 قدم آگے۔
- گوٹی کی پیش رفت `p`: 0 اڈہ، 1–51 ٹریک، 52–56 ہوم کالم (5 نظر آنے والے گھر)، 57 منزل (درمیانی ستارہ)۔

## اصول جو ابھی لگے ہیں

6 پر گوٹی نکلتی ہے · ہر 6 محفوظ ہو جاتا ہے اور دوبارہ پانسہ پھینکتے ہیں، پہلا غیر-6 آنے پر سب محفوظ نمبر کسی بھی ترتیب سے گوٹیوں پر لگتے ہیں (گوٹی پر ٹیپ ← نمبر چنیں) · کٹائی / گھر پہنچنے پر بونس رول · لگاتار تین چھکے پر پوری باری ختم · سیف گھروں پر کٹائی نہیں · منزل پر عین گنتی چاہیے · پوزیشنیں (جب تک ایک کھلاڑی باقی رہ جائے)۔
اصول بدلنے ہوں تو صرف `js/engine.js` دیکھیں۔
